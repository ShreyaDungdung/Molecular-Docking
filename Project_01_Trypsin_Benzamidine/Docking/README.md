# Docking Results

This folder contains the molecular docking output generated using **AutoDock Vina** for the benzamidine–bovine trypsin complex (PDB ID: 3PTB).

## File

- `benzamidine_docked.pdbqt` – Contains the predicted benzamidine binding poses and their corresponding docking scores.

## Docking Details

- **Receptor:** Bovine trypsin
- **Ligand:** Benzamidine
- **Docking software:** AutoDock Vina
- **Best docking affinity:** −6.105 kcal/mol

The docking results were used for binding-pose analysis and redocking validation against the original crystal structure.
