# Docking Results and Analysis

This folder contains the quantitative results obtained from the molecular docking and redocking validation of benzamidine with bovine trypsin (PDB ID: 3PTB).

## Files

- `docking_results.csv` – Contains the docking scores and RMSD values for the nine predicted binding modes generated by AutoDock Vina.
- `redocking_rmsd.txt` – Contains the calculated RMSD between the best docked pose and the experimentally observed benzamidine crystal pose.

## Key Results

- **Best docking affinity:** −6.105 kcal/mol
- **Redocking RMSD:** 0.40 Å

These results were used to evaluate the predicted binding pose and its agreement with the original crystal structure.
