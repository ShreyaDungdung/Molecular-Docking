# Preparation Figures

This folder contains molecular visualization images illustrating the protein and ligand structures used during the preparation stage of the molecular docking study.

## Project

**Molecular Docking and Redocking Validation of Benzamidine with Bovine Trypsin (PDB ID: 3PTB)**

## Figures

| Figure | Filename | Description |
|---|---|---|
| 1 | `Prepared_Trypsin_Protein.png` | Three-dimensional cartoon representation of the bovine trypsin protein structure. |
| 2 | `Prepared_Benzamidine_Ligand.png` | Three-dimensional representation of the protonated benzamidine ligand prepared for docking. |
| 3 | `Trypsin_Binding_Site.png` | Visualization of the benzamidine binding region within the trypsin structure. |
| 4 | `Docking_Grid_Box.png` | Visualization of the docking search space defined around the original ligand-binding site. |

## Visualization Software

- **PyMOL** – Protein and ligand structure visualization.
- **RDKit** – Ligand structure handling and preparation.

## Notes

- The protein structure was obtained from the Protein Data Bank (PDB ID: 3PTB).
- The ligand used in this study was benzamidine (PubChem CID: 2332).
- The figures are intended to document the structural preparation and docking setup.
- All visualizations should correspond to the actual structures and coordinates used in the computational workflow.

## Purpose

These figures provide visual documentation of the molecular structures and preparation steps performed before molecular docking.
